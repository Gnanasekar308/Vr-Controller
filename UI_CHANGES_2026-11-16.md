# UI changes, 2026-11-16 (for the backend merge)

UI only. No networking code added. Base: GitHub `main` at `6402a8e`.

## What changed

1. **Live Scene entry points.** "Live Scene" row (`SettingRow`, icon `view_in_ar`, "Move and rotate objects on the
   Quests") at the end of the **Send** screen (under the preview card) and the **Control** screen; both call
   `nav.Push(ScreenId.Scene)`. New `public Button sceneButton` on `SendScreen` and `ControlScreen`.
   Scene header now has a **Back** button (`BuildScene`: `Header(..., back: true)`, `s.backButton = backB`; the
   existing `SceneScreen.backButton` listener is used).
2. **Live class with demo mode OFF.** New `Classroom.Simulated` (= `AppRoot.Demo`, plus a test-only override).
   When it is false:
   - Live class (admin): Live metrics, Questions, Live comments, the per-student metric list and the **Record** tile
     are hidden; a "Classroom data" card says they come from the classroom server once connected.
   - Live class (student): "My focus" is hidden.
   - Session report: the "Engagement and attention" section is hidden.
   - `Classroom.Tick` no longer generates demo metrics / questions / comments, and `Classroom.Open` no longer adds
     the demo questions / comments.
3. **Battery -1.** `DeviceStatus.Battery(d)` returns "" when the battery is unknown (-1) or the device is offline;
   new `DeviceStatus.Join(...)` joins the non-empty parts with " • ". Devices rows, Create Meeting rows, Meeting
   details rows, the Live student details popup and the student "My Quest" line no longer show "battery --".
   (The Live student rows already hid it.)
4. **Notifications line.** Demo note shortened to "Demo mode: sample data, no network" (`MockControllerService`).
5. **Long station names** (PC server: "LAB-PC-01"...). New `ThemedText.shrinkToFit` / `shrinkMin`: the text gets
   smaller to fit instead of being cut. Used for: Devices row name, "Send to:" / "Playing on:" lines, Create Meeting
   and Meeting details Quest rows, Live student rows (station name), student "My Quest" line, student dashboard
   "My Quest" tile. "Send to:" with more than 2 targets now shows "first +n" (like "Playing on:").
   The Layout Audit now runs with long names ("ANATOMY-LAB-PC-01", "LAB-PC-02"...) and one device with Battery -1,
   and also renders the Live class with demo mode OFF (checks the simulated parts are hidden).
